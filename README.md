# Expense Tracker Frontend (React + Vite)

Modern, responsive web frontend for the Expense Tracker application built with React 18, Vite, Tailwind CSS, and Recharts.

## Getting Started

### Prerequisites
- Node.js >= 20.x
- npm >= 10.x
- Running Expense Tracker Backend (Node.js on port 8086)

### Installation
```bash
cd frontend
npm install
```

### Configuration
Configure your environment variables in `.env`:
```env
VITE_GOOGLE_CLIENT_ID=your_google_oauth_client_id
VITE_API_URL=http://localhost:8086/expense-tracker-api
```

### Running Locally
```bash
# Start development server on port 5173
npm run dev
```

### Production Build
```bash
# Build the production bundle into dist/
npm run build

# Preview the production build locally
npm run preview
```
